# Postman collections (manual exploration only)

Generic MAS 9 collections for poking at the API by hand: per-record extract/deploy/verify/update/delete
for any object structure, and the App Designer presentation flow (`TMG_EXPORT_PRES`).
`maxdev` is the supported route for real changes — it adds ordering, merge safety, read-back and receipts.
Set `baseUrl` and `apikey` in a Postman environment; never commit one with a key in it.
